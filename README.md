# team-profile

チーム開発イベントで作る「チームプロフィールページ」のリポジトリです。
`index.html` をブラウザで開くと、チームのページが表示されます。

## ルール

- `main` ブランチには直接プッシュできません（ブランチ保護設定済み）
- 変更は必ず「ブランチを切る → プルリクエスト → レビュー（Approve 1件） → マージ」の流れで行います
- マージが終わったら `main` に戻って pull してから、次のブランチを切ります

## お題

### サイクル1: 自分の自己紹介ページを追加しよう

1. ブランチ `add-{自分の名前}-profile` を切る（例: `add-wanko-profile`）
2. `members/_template.html` をコピーして `members/{自分の名前}.html` を作り、中身を自分の内容に書き換える
3. `index.html` の自分専用のプレースホルダ行（`<!-- {名前}: ここに自分のリンクを追加 -->`）に、自分のページへのリンクを追加する
4. コミット → プッシュ → プルリクエスト → レビュー → マージ

### サイクル2: チームの共通部分を決めよう（コンフリクト体験）

1. `main` を pull してから、ブランチ `update-theme-{自分の名前}` を切る
2. **全員が同じ行**を自分の案に書き換える:
   - `index.html` のチームキャッチコピーの行
   - `css/style.css` のテーマカラー変数の行
3. コミット → プッシュ → プルリクエスト
4. 2人目以降はコンフリクトが起こる。**チームで話してどの案を残すか決めてから**解消する
5. 解消したらブラウザでページが壊れていないことを確認 → プッシュ → マージ

### サイクル3（自由改善）: 時間が余ったチームへ

好きなものを選んで、サイクルをもう1周まわそう。

- [ ] ダークモード対応（`css/style.css` に `prefers-color-scheme` を追加）
- [ ] 自己紹介ページに「今週の一枚」画像コーナーを追加
- [ ] チームの活動記録セクションを `index.html` に追加
- [ ] フッターに GitHub リポジトリへのリンクを追加
