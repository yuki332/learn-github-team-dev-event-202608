# learn-github-team-dev-event

チーム開発イベントの作業リポジトリです。自分のチームの `team{番号}/` フォルダの中で作業します

## ルール

- `main` ブランチには直接プッシュできません（ブランチ保護設定済み）
- 変更は必ず「ブランチを切る → プルリクエスト → レビュー（Approve 1件） → マージ」の流れで行います
- Approveを誰かにもらってからマージすること
- マージが終わったら `main` に戻って pull してから、次のブランチを切ります
- プルリクエストのタイトルは `[team{#number}] タイトル` にしてください

## お題

### サイクル1: 自分の自己紹介ページを追加しよう

1. ブランチ `add-{自分の名前}-profile` を切る（例: `add-wanko-profile`）
2. `team{number}/_sample.md` をコピーして `{自分の名前}.md` を作り、中身を自分の内容に書き換える
3. アド → コミット → プッシュ → プルリクエスト → レビュー → マージ

### サイクル2: チームの共通部分を決めよう（コンフリクト体験）

1. `main` ブランチを pull してから、ブランチ `update-theme-{自分の名前}` を切る
2. **全員が同じ行**を自分の案に書き換える:
   - `team{number}/main.md` の **キャッチコピーの行**（`## キャッチコピー` の下の1行）
3. アド → コミット → プッシュ → プルリクエスト（注意：マージしない）
4. 2人目以降はコンフリクトが起こる。**チームで話してどの案を残すか決めてから**解消する

### サイクル3（自由改善）: 時間が余ったチームへ

好きなものを選んで、サイクルをもう1周まわそう。

- [ ] `team{番号}/main.md` のメンバー一覧に、全員の自己紹介ページへのリンクを追加する
- [ ] 自己紹介ページに「今週の一枚」コーナーを追加する
- [ ] `team{番号}/main.md` に「チームの今日のふりかえり」セクションを追加する
